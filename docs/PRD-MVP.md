# Quick Reply — MVP Requirements

## Product Overview
Quick Reply is a free, universal AI-powered business communication platform.

## Core Features
1. Google and Email Login
2. Business Profile Setup
3. Ready-made Reply Templates
4. AI Reply Generator
5. Hindi, English, Hinglish and Gujarati
6. Custom Templates
7. Favorites and Search
8. Copy Reply
9. WhatsApp Share with Prefilled Text
10. User Settings

## AI Capabilities
- Generate professional replies.
- Make replies shorter or more polite.
- Translate replies.
- Change tone and language.
- Never invent prices, delivery dates or payment status.

## Design
- White background
- Navy Blue
- Purple accents
- Mobile-first responsive layout

## Technology
- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- OpenAI API

## Pricing
Free for users.
AI usage must have server-side limits and spending controls.

## Project Status
MVP planning and development.
